# السياسات التجارية المعتمدة للإصدار

> اعتمدها المالك في 2026-11-21. يقرأ مسار الإصدار المؤتمت هذا الملف،
> ويرفض بناء نسخة تجارية إذا لم يكن `POLICY_STATUS: APPROVED`.
> أي تعديل على القيم أدناه يجب أن يُقرن بتغيير هذا السطر إلى `PENDING`
> ثم إعادة اعتماده بعد تحديث الكود والاختبارات.

## 1. الضريبة والتقريب

| البند | القيمة المعتمدة |
|---|---|
| النسبة | 14% (`tax_rate_bps = 1400`) |
| طريقة العرض | الأسعار المعروضة **غير شاملة** الضريبة؛ تُضاف 14% عند الدفع |
| التقريب | أقرب **1 جنيه مصري** (100 قرش) على قيمة الضريبة، بترتيب تصاعدي عند ٠.٥٠ ج.م |

القيمة الافتراضية في قاعدة البيانات (`prices_include_tax = 0`) تتوافق مع هذا القرار.
لا تُعرض أسعار شاملة للضريبة في الواجهة التجارية.

## 2. المرتجعات والاستبدال

| البند | القيمة المعتمدة |
|---|---|
| مدة الإرجاع | 14 يومًا من تاريخ الفاتورة |
| الإيصال | غير مطلوب لإتمام المرتجع؛ يُسجَّل رقم الفاتورة في السجل |
| الأصناف المخفضة | مقبولة |
| حالات الإرجاع للمخزون | `UNOPENED` و`NEW_TAGS` فقط |
| حالة القطعة التالفة/المفتوحة | لا تُضاف إلى رصيد `SELLABLE` |
| طريقة رد المبلغ | **رصيد للعميل** (store credit) مسجَّل في `loyalty_ledger` كحدث `ADJUST` |
| الاستبدال | فاتورة جديدة ذرية مع تسجيل فرق السعر |

> ملاحظة تنفيذية: رد المبلغ رصيدًا يتطلب واجهة اختيار «رصيد العميل» في مكتب المرتجعات.
> إلى أن تُفعّل هذه الواجهة، يظل بند الرد في checklist غير مكتمل.

## 3. الترخيص والتسعير

| البند | القيمة المعتمدة |
|---|---|
| تجربة محلية تلقائية | 7 أيام |
| مهلة سماح بعد الانتهاء | 14 يومًا (البيع مسموح أثناءها) |
| خطة سنوية | `annual_1` — **12,000 ج.م/سنة** لمحل/فرع واحد |
| مستخدمون | حتى 5 لخطة المحل الواحد |
| فروع | 1 في الخطة الأساسية |
| نقل الجهاز | مرة واحدة مجانًا، ثم **500 ج.م** لكل نقل إضافي |
| التجربة الموقّعة | `trial_signed` 7 أيام عبر `.req`/`.lic` |
| الدفع | تحويل بنكي أو instapay، مقدمًا سنويًا |
| بعد انتهاء المهلة | إيقاف البيع، السماح بالقراءة والنسخ وإعادة الطباعة |
