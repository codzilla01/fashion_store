## 3. دورة حياة الترخيص

```
                 ┌──────────────────────────────┐
                 │  أول تشغيل على الجهاز        │
                 └──────────────┬───────────────┘
                                │
                 لا يوجد ملف .lic
                                │
                    ┌───────────┴───────────┐
                    ▼                       ▼
          ┌──────────────────┐    ┌────────────────────┐
          │  trial_local     │    │  رخصة موقّعة        │
          │  7 أيام          │    │  (import)           │
          └────────┬─────────┘    └─────────┬──────────┘
                   │                        │
                   ▼                        ▼
          ┌──────────────────┐    ┌────────────────────┐
          │ انتهت التجربة    │    │  ACTIVE             │
          └────────┬─────────┘    │  حتى expires_at    │
                   │              └─────────┬──────────┘
                   ▼                        │ انتهت صلاحيتها
          ┌──────────────────┐              ▼
          │ مهلة سماح        │    ┌────────────────────┐
          │ 14 يومًا         │    │  مهلة سماح 14 يومًا │
          └────────┬─────────┘    └─────────┬──────────┘
                   │                         │
                   └────────────┬────────────┘
                                ▼
                   ┌────────────────────┐
                   │  LICENSE_REQUIRED   │
                   │  إيقاف البيع        │
                   └────────────────────┘
```

### سلوك كل حالة

| الحالة | `valid` | البيع | النسخة | طباعة الفاتورة | البانر |
|---|---|---|---|---|---|
| `ACTIVE` | ✅ | مسموح | مسموح | مسموح | لا |
| `TRIAL_ACTIVE` | ✅ | مسموح | مسموح | مسموح | تجربة محلية |
| `TRIAL_GRACE_PERIOD` | ✅ | مسموح | مسموح | مسموح | مهلة سماح |
| `GRACE_PERIOD` | ✅ | مسموح | مسموح | مسموح | مهلة سماح |
| `LICENSE_EXPIRED` (بعد المهلة) | ❌ | **ممنوع** | مسموح | ❌ | لا |
| `LICENSE_REQUIRED` | ❌ | **ممنوع** | مسموح | ❌ | لا |
| `LICENSE_DEVICE_MISMATCH` | ❌ | **ممنوع** | مسموح | ❌ | لا |
| `LICENSE_SIGNATURE_INVALID` | ❌ | **ممنوع** | مسموح | ❌ | لا |
| `PUBLIC_KEY_NOT_CONFIGURED` | ❌ | **ممنوع** | مسموح | ❌ | تنبيه نسخة تطوير |

> **قرار مطلوب:** هل يجب أن يبقى **البيع مسموحًا** أثناء مهلة السماح؟
> الافتراضي الحالي: نعم — لأن منع البيع في منتصف يوم عمل يضر المتجر.
> البديل: منع البيع والسماح بالقراءة والنسخ فقط.

> **قرار مطلوب:** هل تبقى **الطباعة متاحة** بعد انتهاء المهلة (لطباعة
> مستحقات المتجر)؟ الافتراضي الحالي: لا.

## 4. التجربة المحلية — قيود معروفة يجب承认ها

| الجانب | التنفيذ الحالي | المخاطرة |
|---|---|---|
| بدء التجربة | تلقائي عند أول تشغيل | ✅ |
| مدة التجربة | 7 أيام | قرار تجاري |
| ربط الجهاز | `device_fingerprint` (SHA-256 of SMBIOS UUID) | ⚠️ البصمة تغيّر بتغيّر اللوحة الأم/الـVM |
| منع إعادة التشغيل | صف واحد في `local_trial_state` + trigger append-only | ⚠️ حذف قاعدة البيانات = إعادة التجربة |
| منع تحريك الساعة | `record_trusted_time` يرصد رجوع الساعة 5 دقائق | ⚠️ تقدّم الساعة = تمديد غير مرصود |
| تجاوز بتعديل النظام | **غير مطبّق** | ⚠️ فجوة معروفة |

### إجراءات التحقق من التجربة

1. `local_trial_state` صف واحد فقط، `singleton=1`.
2. Trigger `local_trial_state_no_update` و`local_trial_state_no_delete`.
3. `record_trusted_time` يكتب `last_seen_utc` في `local_license_state`
   ويرفض `CLOCK_ROLLBACK_DETECTED` عند رجوع الساعة أكثر من 5 دقائق.
4. `tests/test_schema_smoke.py::test_local_trial_state_is_singleton_and_append_only`.

### ما يجب قياسه قبل البيع

- [ ] كم مرة طلب العميل إعادة التجربة؟ (لكل طلب: ترخيص جديد على جهاز مختلف)
- [ ] ما نسبة العملاء الذين ينسون التفعيل قبل انتهاء التجربة؟
- [ ] هل 7 أيام كافية لتجربة بيع كاملة (تدريب + بيانات + بيع)؟
- [ ] هل تُقبل سياسة "التجربة مرة واحدة لكل جهاز"؟

## 5. التفعيل والنقل

### المسار العادي

```
العميل ──.req──▶ مسؤول التفعيل ──.lic──▶ العميل
```

- `.req`: بصمة الجهاز + إصدار المنتج + طلب موقّع من المتجر.
- `.lic`: حمولة موقّعة Ed25519 مرتبطة ببصمة الجهاز.

### النقل إلى جهاز جديد

1. طلب `.req` جديد من الجهاز الجديد.
2. إصدار `.lic` جديدة.
3. استيراد `.lic` + استعادة `.bkz`.
4. **لا يُنسخ `db-key.dpapi` بين الأجهزة.**

> **قرار مطلوب:** سياسة النقل — هل مجاني، أم برسوم، وكم مرة مسموح؟
> وما الإجراء إذا فقد العميل الجهاز (سطح المكتب)؟

## 6. آلية إصدار الرخص (داخلية — لا تُوزَّع)

```powershell
cd tools/license-issuer
cargo run --release -- issue `
  --request .\request.req `
  --customer-id CUST-001 `
  --plan annual_1 `
  --private-key-file E:\issuer-secrets\ed25519-seed.bin `
  --features pos.sell,inventory.manage,returns.exchange,reports.basic,backup.restore,customers.manage,import.csv `
  --max-users 5 `
  --max-branches 1
```

### ضوابط إلزامية للمُصدِر

- [ ] المفتاح الخاص (32-byte seed) على جهاز/HSM معزول، **ليس في Git ولا في سحابة**.
- [ ] نسخة احتياطية من المفتاح في مكانين منفصلين.
- [ ] سجل إصدار محلي: التاريخ، العميل، الجهاز، البصمة، الخطة.
- [ ] تدوير المفتاح سنويًا + سياسة إعادة إصدار لكل العملاء.
- [ ] المفتاح العام corresponding يجب أن يُحقن في كل بناء جديد.

### ⛔ حالة المفتاح العامة الآن

| البند | الحالة |
|---|---|
| مفتاح إصدار إنتاجي | **غير موجود** |
| `NASEEJ_LICENSE_PUBLIC_KEY_HEX` في CI | **غير مضبوط** (secret فارغ) |
| أثر ذلك | كل بناء من CI هو **نسخة تطوير** — يرفض التطبيق أي رخصة موقّعة |
| الحماية المضافة | `is_production_key_configured()` → تحذير أحمر في الواجهة + `PUBLIC_KEY_NOT_CONFIGURED` |

> **هذا مقصود**: لا يمكن إنتاج نسخة "للبيع" قبل إنشاء مفتاح حقيقي.
> الخطر الوحيد هو أن يُسلَّم بناء تطوير بالخطأ — ولهذا التنبيه ظاهر داخل
> التطبيق نفسه، لا في مستند فقط.

## 7. البنود القانونية (RIGHTS.txt — مسودة)

النقاط التالية تحتاج **مراجعة محامٍ** قبل الاعتماد:

1. **الترخيص**: nonexclusive, non-transferable license to install and use
   the software on the number of devices/branches in the plan.
2. **عدم إعادة التوزيع**: no redistribution of the installer, no reverse
   engineering, no resale.
3. **البيانات**: customer data remains the customer's; the vendor stores
   no customer data on its systems (the product is fully offline).
4. **الدعم**: ما الذي يشمله الاشتراك؟ ساعات العمل؟ SLA للاستجابة؟
5. **الضمان**: no warranty; liability capped at fees paid.
6. **إنهاء الاشتراك**: what happens to data when the subscription ends?
   (Current behaviour: read-only + backup allowed, selling blocked.)
7. **الاسترجاع**: refund policy.
8. **الاختصاص القضائي**: مصر.
